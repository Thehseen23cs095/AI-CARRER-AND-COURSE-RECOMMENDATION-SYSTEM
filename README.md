# AI Career and Course Recommendation System

## 📌 Project Overview

The AI Career and Course Recommendation System is a web-based platform designed to help students and job seekers choose suitable career paths based on their skills, interests, and profile.

The system provides career recommendations, skill-gap analysis, course and learning-resource suggestions, mock interview support, internship opportunities, events, chatbot assistance, and an ATS-based resume checker.

## 🎯 Objectives

- Recommend suitable career paths based on user profiles
- Identify skill gaps for selected career roles
- Suggest relevant courses and learning resources
- Help users prepare for interviews
- Provide internship and career-related opportunities
- Check resumes using ATS-based analysis

## 💡 How It Works

1. Users create an account and complete their profile.
2. The system analyzes their skills and interests.
3. Suitable career paths are recommended.
4. The system identifies missing skills.
5. Relevant courses and resources are suggested.
6. Users can use mock interviews, chatbot support, internships, events, and resume analysis.

## 📂 Project Structure

The project contains the Flask application, frontend pages, static files, database configuration, and supporting resources required to run the system.
